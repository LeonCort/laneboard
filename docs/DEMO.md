# Three-minute demo

1. **Start (20 seconds).** Open Laneboard. Point out that journeys stay on the device. Open “Small business owner starts investing”. Show phases, channel lanes and the customer’s goal.
2. **See the problem (40 seconds).** Open Services. Surplus analysis is only in the internet bank; the guide is only in the app. Read the single-channel rule. Show that isolated account opening fits a webview, while the linked inflation tool cannot use one as a fix.
3. **Compare (25 seconds).** Close the drawer and switch to Target. Restarts fall from two to zero and coverage changes. Point out the “Changed” service statuses and improved experience curve.
4. **Edit (35 seconds).** Duplicate the example, switch to Now and change the surplus analysis’s app status to Native in Services. The map, rules, capabilities and KPIs update together. Undo and redo.
5. **Overview and present (25 seconds).** Switch to Overview to show the shared goal, indicators and owner frictions. Return to Canvas; the map keeps its position. Use Present, then arrow keys. Exit with Escape. Open the mortgage example to show the default six-step walkthrough and an assisted-to-digital journey.
6. **Share (30 seconds).** Export a workspace backup and a PNG. Open Create with AI, describe a scenario and copy the prompt. Explain that the assistant is outside Laneboard and its JSON reply returns through the same validated import.
7. **Finish (5 seconds).** Remind everyone to export backups and keep personal customer data out of journey maps.
