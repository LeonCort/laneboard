# Improvements from the usability audit

The product changes below address all ten priorities in the audit. The existing inline lane editing, hiding, restoring and group controls remain available.

| Audit finding                                       | Implemented behavior                                                                                                                                                                                                                                                                         |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Selecting and editing a service can crash           | Service selections are deduplicated across channel instances. Coverage changes, links, undo and reload have browser regressions.                                                                                                                                                             |
| Presentation can show an empty map                  | Slide sequences remain stable and nodes declare their dimensions before fitting. Tests check visible service and journey cards after import, view changes and reload.                                                                                                                        |
| Narrow windows lose Library and details             | Temporary, accessible side panels provide the same editing controls at narrow widths. Escape closes them while preserving the selected card.                                                                                                                                                 |
| Fit hides content beneath panels                    | Fit uses the space between lane labels, tools and details, with room for bottom controls. Zoom and Fit stay visible when tools close.                                                                                                                                                        |
| Target percentages imply unsupported improvements   | New journeys require an explicit copy of Now. Services start unassessed. Target changes show added/removed steps, status and experience changes, coverage counts, unassessed and excluded pairs. Design review returns to Draft after relevant edits. Existing Target designs are preserved. |
| Starting with a blank map is difficult              | A two-step, skippable setup captures the customer, situation, goal, hypothesis, test, next action, evidence and first customer action.                                                                                                                                                       |
| Modes compete for attention                         | Canvas, Data and Overview are stable primary views. Present has one entry in the top action bar; sketch tools remain secondary.                                                                                                                                                              |
| Building a story needs repeated trips to details    | Cell menus create cards in their location. Data → Steps supports inline text/location/transition editing, context-aware next steps and keyboard-friendly ordering.                                                                                                                           |
| Overview contains an unrelated organization diagram | Overview summarizes this journey’s hypothesis, evidence, validation action, owners, owned lanes/frictions and handoffs.                                                                                                                                                                      |
| IDs, slugs and tiny cards are hard to interpret     | Frictions have readable references, inferred capabilities have readable names, transitions use human labels, and selected details remain readable in temporary panels. Automatic service checks are separate from recorded customer frictions.                                               |

Prepare AI prompt now describes the actual prompt-and-import workflow. Error recovery offers an export of current edits before reload and explains that reload restores the last successful save. Journey, lane, service, step and friction evidence can be unassessed, assumed or validated with supporting notes. Saved workspaces migrate without replacing existing journey designs.

Validation covers model behavior, browser workflows, narrow windows, keyboard controls, accessibility, persistence, offline use, exports and imports. The audit’s representative-user study still requires recruiting real participants; these checks do not validate a customer hypothesis. See [the user guide](USER-GUIDE.md) for the updated controls.
