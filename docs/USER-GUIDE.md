# Laneboard user guide

Laneboard maps a customer journey across channels. The map, services table, capabilities and KPIs all describe the same data. Your work is saved automatically in this browser; nothing is uploaded. Map journeys, never personal customer data.

**Context commands.** Right-click a card, cell, lane label, group or phase to open commands for that item. Cards offer details, Copy, Duplicate and Delete; services and feeds also offer Add link to open connection search. Cells offer the card types supported by that lane. Lane labels offer Edit, Lock/Unlock and Hide; groups offer Collapse/Expand and Add lane within that group. Right-click empty canvas space for Paste, Add lane, Add phase, Fit and the command palette. Undo/Redo appear in every menu. Locked cards and read-only examples explain their restrictions. Press Shift+F10 or the keyboard menu key on a focused map item to open its menu, use arrow keys and Enter, and press Escape to dismiss it. Text fields retain their native menu. Hold Shift while right-clicking to use the browser menu. Panning uses the middle button, the Hand tool or Space+left-drag.

**Get started.** Open either Example Bank journey from the welcome screen, then select **Duplicate to edit**. Or start with bank channels or blank lanes. A short, skippable setup records the customer, situation, goal, hypothesis, test and first customer action. Use Open details in Overview to revisit it. Switch journeys from the left panel. The journey menu lets you duplicate, rename or delete a journey; deleting requires confirmation.

**Choose a view.** The journey title sits in the top-left Laneboard panel; click it to edit journey details. Use **Canvas / Data / Overview** in the top bar to switch between the map, editable lists and a summary of the hypothesis, evidence, actual owners, handoffs and next validation action. The canvas keeps its position and selection, and Data keeps its selected tab. Selecting a friction in Overview returns to its card on the canvas. Overview also follows the Now / Target switch.

**Build the map.** Phases are columns and lanes are rows. Select a phase or lane in the left tree to edit its name and properties in the inspector. Add lanes, phases or groups with the plus buttons or Library. Drag tree rows to reorder; the inspector also has keyboard-friendly move buttons. Drag a phase’s right edge to resize it. Hide lanes, lock them or collapse groups. Customer notes and the experience curve appear above the channel map; drag a curve point or edit the value through the command palette/inspector.

**Edit lanes in place.** Click a lane label on the canvas to rename it, change its subtitle or move it to another group. Select **Save** or press Enter to apply the changes; Escape or Cancel discards them. **Hide lane** saves the current details and hides the row without removing its cards. The **Hidden lanes** eye icon above the lane labels restores a row. Use the **+** beside a group heading to add a named lane directly into that group, or the **+** above the lane labels to choose any group. Empty groups keep their add control. Adding, moving or showing a lane opens its destination group and brings the row into view. These controls also work with the journey pane collapsed, and Ctrl/Cmd+Z undoes the changes.

**Add cards.** A quick double-click on a cell’s + opens one menu. Add lane on a read-only example offers Duplicate to edit and keeps the add form open in the editable copy. Hover or keyboard-focus a cell to reveal its + menu. It places the card directly in that lane and phase. Choose a dock tool and click a cell, or double-click a cell for a picker. The Library and command palette can place a card without a mouse. S creates a service, J a journey step, F a friction, E a feed and N a note. Double-click card text for inline editing, or select a card to show its details. Clearing the selection closes the detail pane. Drag cards into another cell. Shift-drag selects several; Ctrl/Cmd-click adds to a selection. Copy, paste, duplicate or delete cards. Ctrl/Cmd+Z undoes changes; Ctrl/Cmd+Shift+Z redoes them.

**Services and rules.** New services start as **Not assessed**, including their flow connection. Assess each digital channel as native, webview, information, open in browser, missing, planned or not applicable. Open **Data → Services** to edit statuses in the selected mode. Set the flow connection to isolated or connected only when known. Adding a link sets the flow to connected and locks that choice while links exist. Rules flag linked webviews and single-channel services, explain the problem and list required technical capabilities. Capabilities are technical abilities, separate from customer-facing services.

**App referrals and web characteristics.** Use **Information** when the app only tells the customer to visit the web, or **Open in browser** when it offers a direct link that opens outside the app. In the service details, choose the **Web destination** for that service and select **Edit destination characteristics**. Record **Legacy / Modern system** and **Responsive / Not responsive** on the destination channel; both start as Not assessed. Rules warn against linking to a legacy or non-responsive service, an unavailable service, or a destination that still needs assessment. Modern technology alone does not establish responsiveness. These are planning assessments, not an automated inspection of a website. Browser access does not count as native app coverage. Characteristics are separate for Now and Target, copied by Create Target from Now, listed in Target changes, and included in JSON and CSV exports. Data → Services offers a Characteristics link for each channel. Lane details let you set a channel’s platform to Mobile app or Website / internet bank independently of its ability to host a webview.

**Connect cards.** Hover over a service, feed or journey step, or focus its + with the keyboard. Click **+** to search for a connection by name, phase or lane, then choose a result with a click or Enter. Or drag **+** directly onto another card; valid targets have a green outline and the whole card accepts the drop. Services connect to other services and show directional dashed lines on the map. Choose an already connected service in the search picker to remove that link. A feed points to one journey step; choosing another step replaces its current connection. Journey steps connect to other steps in the active Now or Target mode. Both methods save automatically, travel in JSON exports and support Undo/Redo. Read-only examples offer Duplicate to edit; locked lanes must be unlocked first.

**Change a connection.** Click a line to highlight it and reveal handles at both ends. Drag either handle onto a compatible card, or use **Source / Destination** in the floating controls to search for a replacement. An empty or incompatible drop keeps the original connection. The trash button, Delete/Backspace or **Delete connection** in the line’s right-click menu removes the line and keeps its cards. A feed can remain unconnected; editing a journey path keeps the step order and changes only the active mode. Undo restores the previous connection in one step. Keyboard users can focus a line and press Enter to select it. Escape or clicking empty canvas dismisses the controls. Read-only and locked connections remain inspectable with editing disabled.

**Compare now and target.** New journeys have no Target design until you choose **Create Target from Now**. This copies Now exactly. Existing imported targets are preserved. **Data → Target changes** lists differences and shows native coverage with its numerator and denominator, unassessed pairs and excluded pairs. Excluding a channel can raise the percentage without adding native availability. Mark a design reviewed after inspecting it; later Target edits return it to Draft. Review does not validate a hypothesis. The top-right switch changes statuses, visible steps, edge transitions, experience values, rules and KPIs. Changed service statuses receive a highlight and a “Changed” tag. In the investing example, restarts drop from two to zero. Target friction text is a recommendation, not a claim that a problem has already been resolved.

**Layers and filters.** Toggle services, journey, frictions, feeds, market, owners or sketches in the inspector. Click the search icon in the top bar to expand search and its filters. Close search with the × button or Escape; active filters keep the search icon highlighted. Search card text and use the filters for owner, severity or lane; non-matching items are dimmed. The Owners layer outlines lanes and frictions by owner, with owner chips to filter the map. Definitions lets you maintain shared owners and capabilities. Overview shows only owners referenced by this journey, their lanes and frictions, and handoffs between differently owned lanes.

**Sketch.** Switch the dock to Sketch and use rectangle (R), ellipse (O), arrow (A), text (T) or sticky note (N). Place a shape, resize it with its handles or numeric size fields, and edit it in the inspector. Pin it to a lane and phase so it follows the cell, or let it float. Position and pinned-offset fields let you move sketches with the keyboard. Press Enter or Tab to apply a numeric edit; Escape cancels it. The Sketches layer hides all annotations. Q keeps a tool active after placement. H or Space+drag pans; Ctrl/Cmd+scroll, pinch and +/− zoom. Use Fit to screen to see the whole map.

**Present.** Select the play icon in the top bar for a full-screen guided walkthrough. Arrow keys move through the steps and Escape exits. Imported presentation steps are used when supplied; otherwise six default steps introduce services, journey, frictions, feeds, market and owners. Each slide selects layers and focuses lanes automatically. Phase headers stay aligned with the map columns, and fitting leaves space for lane labels and the presentation controls. Exiting returns to your previous view and canvas position.

**Laneboard files.** Keep each Laneboard in its own `.laneboard.json` file and work on it like a document. **Open Laneboard file…** (Ctrl/Cmd+O) replaces the workspace with the file's journeys, owners, capabilities, name, accent and logo; theme and language stay as they are. **Save** (Ctrl/Cmd+S, or click the file name in the top bar) writes back to the same file. **Save as…** (Ctrl/Cmd+Shift+S) writes a new file and continues there, so you can branch one Laneboard into another. **New empty Laneboard** starts over without a file. The file name in the top bar gets a dot, and the tab title a •, while there are unsaved changes; undoing back to the saved state clears it. Before opening another file or starting a new one, Laneboard asks if that would lose work not saved to a file. Your work is still saved in this browser between visits, so the file is your copy to keep, move and share. Chrome and Edge save over the file, also when Laneboard is opened as a downloaded HTML file, and may ask once for permission after a reload. Firefox and Safari cannot write to files, so Save downloads a new copy with the same name.

**Import and AI.** Import `.laneboard.json` or `.json` with the picker, drop it on the window or paste JSON. Review the title, counts, warnings and errors before committing. Choose add as new journeys or replace matching IDs; a backup can also restore settings and view state. Files over 5 MB or broken references are rejected without changing your workspace. **Prepare AI prompt** takes your scenario and notes, then copies a prompt containing the schema and example. Nothing is sent: paste it into your approved assistant, save its JSON reply and import it.

**Export and protect your work.** Select the download icon in the top bar to export a journey or whole workspace as JSON. Save a backup at least every two weeks, and before clearing browser data. PNG and SVG capture the current canvas view, mode and layers at 1× or 2×. Export services or frictions as CSV; print a data table with your browser’s print-to-PDF feature. Save to file uses the browser’s local file picker where supported, and falls back to a download elsewhere.

**Settings and shortcuts.** Set English or Swedish, light / dark / system theme, accent and a small local logo. Ctrl/Cmd+K opens the command palette. Ctrl/Cmd+\\ collapses the journey pane. The navigation, sketch dock and selected details stay available. Use **Expand** or select **Journeys** or **Library** to reopen the left pane. Shift+M switches now/target. Press ? for the shortcut sheet. Install the app from your browser’s app menu when supported; it works offline after the first complete visit. The “Saved in this browser” indicator confirms each save. If saving fails, immediately export a backup. If the editor fails, Export recovery copy captures the current workspace before reloading; reloading restores the last successfully saved state.

**Build the customer story.** In **Data → Steps**, edit text, lane, phase and readable transition labels directly. **Add next step** inherits the previous location, and uses Continue here for the same lane or Change channel / Get support for a new lane. Move buttons reorder steps without opening the inspector. Evidence and notes sit inside an expandable section. New steps belong to the active mode after Target is created.

**Evidence and narrow windows.** Journey details, lanes, services, steps and frictions can be Not assessed, an Assumption or Validated with supporting notes. These states are user assessments; automatic service checks are separate from researched customer frictions. At narrow widths, Journeys and Library open temporary side panels, and selecting a card opens readable details. Escape closes the panel. The rail, dock, zoom and Fit controls remain available with the journey pane collapsed. Selected details open independently.
