# Laneboard user guide

Laneboard maps a customer journey across channels. The map, services table, capabilities and KPIs all describe the same data. Your work is saved automatically in this browser; nothing is uploaded. Map journeys, never personal customer data.

**Get started.** Open either Example Bank journey from the welcome screen, then select **Duplicate to edit**. Or start with bank channels or blank lanes. A short, skippable setup records the customer, situation, goal, hypothesis, test and first customer action. Use Open details in Overview to revisit it. Switch journeys from the left panel. The journey menu lets you duplicate, rename or delete a journey; deleting requires confirmation.

**Choose a view.** The journey title sits in the top-left Laneboard panel; click it to edit journey details. Use **Canvas / Data / Overview** to switch between the map, editable lists and a summary of the hypothesis, evidence, actual owners, handoffs and next validation action. The canvas keeps its position and selection, and Data keeps its selected tab. Selecting a friction in Overview returns to its card on the canvas. Overview also follows the Now / Target switch.

**Build the map.** Phases are columns and lanes are rows. Select a phase or lane in the left tree to edit its name and properties in the inspector. Add lanes, phases or groups with the plus buttons or Library. Drag tree rows to reorder; the inspector also has keyboard-friendly move buttons. Drag a phase’s right edge to resize it. Hide lanes, lock them or collapse groups. Customer notes and the experience curve appear above the channel map; drag a curve point or edit the value through the command palette/inspector.

**Edit lanes in place.** Click a lane label on the canvas to rename it, change its subtitle or move it to another group. Select **Save** or press Enter to apply the changes; Escape or Cancel discards them. **Hide lane** saves the current details and hides the row without removing its cards. The **Hidden lanes** menu beside the view switch restores a row. Use the **+** beside a group heading to add a named lane directly into that group, or the **+** beside the view switch to choose any group. Empty groups keep their add control. Adding, moving or showing a lane opens its destination group and brings the row into view. These controls also work with the tool panels closed, and Ctrl/Cmd+Z undoes the changes.

**Add cards.** Hover or keyboard-focus a cell to reveal its + menu. It places the card directly in that lane and phase. Choose a dock tool and click a cell, or double-click a cell for a picker. The Library and command palette can place a card without a mouse. S creates a service, J a journey step, F a friction, E a feed and N a note. Double-click card text for inline editing, or select a card to use the inspector. Drag cards into another cell. Shift-drag selects several; Ctrl/Cmd-click adds to a selection. Copy, paste, duplicate or delete cards. Ctrl/Cmd+Z undoes changes; Ctrl/Cmd+Shift+Z redoes them.

**Services and rules.** New services start as **Not assessed**, including their flow connection. Assess each digital channel as native, webview, information, missing, planned or not applicable. Open **Data → Services** to edit statuses in the selected mode. Set the flow connection to isolated or connected only when known. Adding a link sets the flow to connected and locks that choice while links exist. Rules flag linked webviews and single-channel services, explain the problem and list required technical capabilities. Capabilities are technical abilities, separate from customer-facing services.

**Compare now and target.** New journeys have no Target design until you choose **Create Target from Now**. This copies Now exactly. Existing imported targets are preserved. **Data → Target changes** lists differences and shows native coverage with its numerator and denominator, unassessed pairs and excluded pairs. Excluding a channel can raise the percentage without adding native availability. Mark a design reviewed after inspecting it; later Target edits return it to Draft. Review does not validate a hypothesis. The top-right switch changes statuses, visible steps, edge transitions, experience values, rules and KPIs. Changed service statuses receive a highlight and a “Changed” tag. In the investing example, restarts drop from two to zero. Target friction text is a recommendation, not a claim that a problem has already been resolved.

**Layers and filters.** Toggle services, journey, frictions, feeds, market, owners or sketches in the inspector. Search card text and use the filters for owner, severity or lane; non-matching items are dimmed. The Owners layer outlines lanes and frictions by owner, with owner chips to filter the map. Definitions lets you maintain shared owners and capabilities. Overview shows only owners referenced by this journey, their lanes and frictions, and handoffs between differently owned lanes.

**Sketch.** Switch the dock to Sketch and use rectangle (R), ellipse (O), arrow (A), text (T) or sticky note (N). Place a shape, resize it with its handles or numeric size fields, and edit it in the inspector. Pin it to a lane and phase so it follows the cell, or let it float. Position and pinned-offset fields let you move sketches with the keyboard. Press Enter or Tab to apply a numeric edit; Escape cancels it. The Sketches layer hides all annotations. Q keeps a tool active after placement. H or Space+drag pans; Ctrl/Cmd+scroll, pinch and +/− zoom. Use Fit to screen to see the whole map.

**Present.** Select Present for a full-screen guided walkthrough. Arrow keys move through the steps and Escape exits. Imported presentation steps are used when supplied; otherwise six default steps introduce services, journey, frictions, feeds, market and owners. Each slide selects layers and focuses lanes automatically. Phase headers stay aligned with the map columns, and fitting leaves space for lane labels and the presentation controls. Exiting returns to your previous view and canvas position.

**Import and AI.** Import `.laneboard.json` or `.json` with the picker, drop it on the window or paste JSON. Review the title, counts, warnings and errors before committing. Choose add as new journeys or replace matching IDs; a backup can also restore settings and view state. Files over 5 MB or broken references are rejected without changing your workspace. **Prepare AI prompt** takes your scenario and notes, then copies a prompt containing the schema and example. Nothing is sent: paste it into your approved assistant, save its JSON reply and import it.

**Export and protect your work.** Export a journey or whole workspace as JSON. Save a backup at least every two weeks, and before clearing browser data. PNG and SVG capture the current canvas view, mode and layers at 1× or 2×. Export services or frictions as CSV; print a data table with your browser’s print-to-PDF feature. Save to file uses the browser’s local file picker where supported, and falls back to a download elsewhere.

**Settings and shortcuts.** Set English or Swedish, light / dark / system theme, accent and a small local logo. Ctrl/Cmd+K opens the command palette. Ctrl/Cmd+\\ closes the tool panels while keeping the left navigation visible. Use its **Expand** button to reopen the tools, or select **Journeys** or **Library** to reopen that panel. Shift+M switches now/target. Press ? for the shortcut sheet. Install the app from your browser’s app menu when supported; it works offline after the first complete visit. The “Saved in this browser” indicator confirms each save. If saving fails, immediately export a backup. If the editor fails, Export recovery copy captures the current workspace before reloading; reloading restores the last successfully saved state.

**Build the customer story.** In **Data → Steps**, edit text, lane, phase and readable transition labels directly. **Add next step** inherits the previous location, and uses Continue here for the same lane or Change channel / Get support for a new lane. Move buttons reorder steps without opening the inspector. Evidence and notes sit inside an expandable section. New steps belong to the active mode after Target is created.

**Evidence and narrow windows.** Journey details, lanes, services, steps and frictions can be Not assessed, an Assumption or Validated with supporting notes. These states are user assessments; automatic service checks are separate from researched customer frictions. At narrow widths, Journeys and Library open temporary side panels, and selecting a card opens readable details. Escape closes the panel. The rail, zoom and Fit controls remain available with tools closed. Open details also works in a clean canvas.
